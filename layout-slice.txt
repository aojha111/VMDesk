10. DRAG-DROP
=============

When a user drags a file over the remote session:

┌────────────────────────────────────────────┐
│                                            │
│          ↓ Drop files to transfer ↓       │
│                                            │
└────────────────────────────────────────────┘

Use a translucent Windows 11-style drop overlay.

The overlay must disappear when the drag operation ends.
